# Bug Report Collection

## Description

This project demonstrates manual software testing performed on the [nopCommerce Demo Store](https://demo.nopcommerce.com/).

It includes test cases for registration, login, product search, checkout and customer-profile features. It also contains a reproducible bug report with screenshot evidence.

## Testing Performed

- Functional testing
- Positive testing
- Negative testing
- Validation testing
- Exploratory testing

## Project Contents

- `Test-Cases/` – Manual test cases with steps, expected results, actual results and statuses
- `Bug-Reports/` – Documented defects with severity, priority and reproduction steps
- `Screenshots/` – Visual evidence for reported defects
